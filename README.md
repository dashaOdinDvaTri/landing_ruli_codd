# ЦОДД.Гараж — лендинг-инструкция

Адаптивный лендинг с инструкцией по использованию мобильного приложения
«ЦОДД.Гараж». Интерфейс свёрстан по мобильным макетам Figma и включает
информационные секции, ссылки на магазины приложений, анимации появления
контента и доступный FAQ-аккордеон.

## Стек

- HTML5;
- CSS3 и PostCSS с Autoprefixer;
- JavaScript (ES modules);
- Vite 7;
- локальные изображения, SVG-иконки и шрифты Moscow Sans.

## Требования

- Node.js `20.19+` или `22.12+`;
- npm `10+`.

## Установка и локальный запуск

```bash
npm ci
npm run dev
```

После запуска Vite выведет локальный адрес проекта в терминале.

## Production-сборка

```bash
npm run build
```

Готовые файлы будут созданы в каталоге `dist/`.

Для локальной проверки production-сборки:

```bash
npm run preview
```

## Переменные окружения

Проект не использует переменные окружения, поэтому файл `.env` для запуска не
требуется.

## Поддерживаемые мобильные разрешения

- 320 px;
- 375 px;
- 390 px;
- 430 px.

Промежуточные мобильные ширины поддерживаются адаптивными CSS-правилами.

## Ссылки магазинов

Ссылки RuStore и App Store вынесены в `src/scripts/config.js`. Сейчас стоят базовые URL магазинов, их можно заменить на прямые ссылки приложения.

## Структура

- `index.html` — семантическая разметка лендинга.
- `src/main.js` — точка входа клиентского кода.
- `src/styles/` — базовые стили, композиция, компоненты, адаптив и анимации.
- `src/scripts/` — конфигурация, FAQ, ссылки магазинов и анимации.
- `public/assets/figma/` — локальные ассеты, экспортированные из Figma.
- `public/assets/fonts/` — локальные начертания Moscow Sans, подключённые через `@font-face`.
- `vite.config.js` — конфигурация dev-сервера и production-сборки.
- `postcss.config.js` — конфигурация Autoprefixer.
